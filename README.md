# Lab Manager

Расширение для VS Code, которое помогает организовать учебные
проекты: быстро открывать работы, отмечать их статус и держать
условия, отчёты и полезные ссылки рядом с кодом.

## Возможности

- Сохранение учебных проектов в одном списке.
- Группировка по предметам в боковой панели.
- Поиск по названию и предмету.
- Открытие папки проекта в новом окне VS Code.
- Изменение названия, предмета и пути к папке.
- Удаление записи без удаления файлов.
- Статусы: «Не начата», «В работе», «Готова», «Сдана».
- Фильтр для отображения только несданных работ.
- Прикрепление локальных файлов и веб-ссылок.
- Открытие материалов через системные приложения и браузер.
- Обновление пути к перемещённому файлу.
- Открепление материалов без удаления самих файлов.
- Сохранение данных между запусками VS Code.

## Установка

Для использования расширения потребуется VS Code
версии 1.140.0 или новее и установочный файл `.vsix`.

1. Откройте раздел Extensions через `Ctrl+Shift+X`.
2. Нажмите кнопку `…` в заголовке раздела.
3. Выберите «Install from VSIX…».
4. Укажите установочный файл расширения.
5. Если VS Code предложит перезагрузить окно, подтвердите действие.

После установки в разделе Explorer появится панель
«Учебные проекты».

Для обычного использования не нужны Node.js, npm,
компиляция исходников или запуск через F5.

## Как пользоваться

### Добавление проекта

1. Откройте папку учебной работы в VS Code.
2. Нажмите `Ctrl+Shift+P`.
3. Выберите «Lab Manager: Добавить проект».
4. Введите название работы и предмет.

Проект появится в панели «Учебные проекты».
Одну и ту же папку нельзя добавить повторно.

Название записи может отличаться от имени папки.
Его изменение в плагине не переименовывает папку на диске.

### Поиск и открытие

Вызовите команду «Lab Manager: Показать проекты»
через `Ctrl+Shift+P`.

Начните вводить название работы или предмет, затем выберите
проект. Его папка откроется в новом окне VS Code.

Открыть проект также можно через контекстное меню:
нажмите правой кнопкой на запись и выберите «Открыть проект».

Если папка недоступна, расширение предложит указать
её новое расположение.

### Редактирование и удаление

Нажмите правой кнопкой на проект. В меню доступны:
- изменение названия и предмета;
- изменение пути к папке;
- изменение статуса;
- прикрепление материала;
- удаление записи из списка.

Удаление требует подтверждения и не затрагивает
папку проекта или её содержимое.

### Статусы работ

Для изменения статуса выберите «Изменить статус»
в контекстном меню проекта.

Доступны четыре варианта:

| Статус | Значение |
|---|---|
| Не начата | Вы ещё не приступили к работе |
| В работе | Работа выполняется |
| Готова | Работа закончена, но ещё не сдана |
| Сдана | Работа сдана |

Новые проекты получают статус «Не начата».
Статус отображается рядом с названием и меняется вручную.

### Фильтр несданных работ

Нажмите кнопку с воронкой в заголовке панели
«Учебные проекты».

Она переключает два режима:
- «Все» — отображаются все проекты;
- «Только несданные» — скрываются работы со статусом «Сдана».

Фильтр не удаляет записи. Повторное нажатие возвращает
полный список. Выбранный режим сохраняется после перезапуска.

Поиск через «Показать проекты» работает по всем записям,
даже если часть из них скрыта фильтром.

### Прикрепление материалов

1. Нажмите правой кнопкой на проект.
2. Выберите «Прикрепить материал».
3. Укажите тип: локальный файл или веб-ссылка.
4. Выберите файл либо введите полный адрес страницы.
5. Задайте название, например «Условие» или «Отчёт».

Раскройте проект стрелкой, чтобы увидеть материалы.

```text
ИСРПО
└── Лабораторная №3 · В работе
    ├── Условие
    ├── Отчёт
    └── Репозиторий
```

Плагин сохраняет путь к файлу, а не копирует его.
Для веб-ссылок разрешены адреса HTTP и HTTPS.

У проекта с материалами нажатие раскрывает вложенный список.
Чтобы открыть саму папку, используйте контекстное меню
или команду поиска проектов.

### Открытие и открепление материалов

Выберите материал в дереве или воспользуйтесь его
контекстным меню.

Локальные файлы открываются системными приложениями,
а веб-ссылки — браузером. Для открытия документа
на компьютере должна быть установлена подходящая программа.

Если файл перемещён, укажите его новое расположение
через «Изменить путь материала». После обновления пути
откройте материал повторно.

Команда «Открепить материал» удаляет только прикрепление
из списка. Сам файл остаётся на компьютере.

## Хранение данных

Данные сохраняются локально в `globalState`
расширения VS Code для текущего профиля.

Хранятся:
- названия проектов и предметов;
- пути к папкам;
- статусы;
- названия и адреса материалов;
- состояние фильтра.

Исходники проектов и содержимое прикреплённых документов
в хранилище не копируются и на внешние серверы не отправляются.

При открытии веб-ссылки браузер обращается
к соответствующему сайту.

## Ограничения

- Поддерживаются только локальные папки.
- При добавлении проекта должна быть открыта одна
  корневая папка.
- Облачной синхронизации между компьютерами нет.
- Операции Git не выполняются.
- Статусы не определяются автоматически.
- Файлы материалов не копируются и не синхронизируются.
- После перемещения папки или файла требуется обновить путь.
- Названия предметов при группировке учитывают регистр.
- Изменять список одновременно из нескольких окон
  не рекомендуется. Для перечитывания данных используйте
  команду «Обновить список».

## Запуск для разработки

Этот раздел нужен для работы с исходным кодом.
Для использования установленного `.vsix` эти действия
не требуются.

Понадобятся:
- VS Code версии 1.140.0 или новее;
- Node.js и npm.

Откройте корневую папку исходников, в которой находится
`package.json`, и выполните:

```bash
npm install
npm run compile
npm run lint
```

После успешной проверки нажмите `F5`.
Откроется тестовое окно Extension Development Host
с подключённым расширением.

## Структура исходников

```text
src/
├── extension.ts       — регистрация команд и подключение панели
├── project.ts         — типы проектов, статусов и материалов
├── projectStorage.ts  — чтение, проверка и сохранение данных
├── projectTree.ts     — дерево проектов и фильтрация
└── projectManager.ts  — команды, диалоги и проверки
```

Техническое задание находится в файле `TZ.md`.
