# Техническое задание: Lab Manager

## Для чего нужен плагин

Lab Manager — расширение для VS Code, которое помогает
хранить учебные проекты в одном списке и быстро их открывать.

Для каждой работы можно указать предмет и статус,
а также прикрепить условие, отчёт и полезные ссылки.

## Какие данные хранятся

Для каждого проекта сохраняются:
- название работы;
- путь к папке на компьютере;
- предмет;
- статус работы;
- список прикреплённых материалов.

Для материала сохраняются его название,
тип и путь к файлу либо адрес веб-страницы.

## Что должен уметь плагин

### 1. Добавление проекта

Пользователь открывает папку в VS Code и вызывает команду
добавления проекта. Плагин получает путь к этой папке,
спрашивает название работы и предмет, затем сохраняет запись.

Одну и ту же папку нельзя добавить повторно.
Название и предмет не должны быть пустыми.

### 2. Список проектов

Проекты отображаются в разделе «Учебные проекты»
в боковой панели VS Code и группируются по предметам.

Предметы и проекты внутри них сортируются по названию.

### 3. Поиск и открытие

Пользователь может найти проект по названию или предмету
без учёта регистра.

Выбранная папка открывается в новом окне VS Code.
Перед открытием плагин проверяет, существует ли она.
Если папка недоступна, предлагает указать новое расположение.

### 4. Изменение и удаление

Можно изменить название проекта, предмет и путь к папке.

При смене пути проверяется, что папка ещё не используется другим проектом в списке.

Удаление записи выполняется после подтверждения.
Сама папка и файлы проекта при этом не удаляются.

### 5. Статусы работ

У проекта может быть один из четырёх статусов:
- Не начата;
- В работе;
- Готова;
- Сдана.

Новый проект получает статус «Не начата».
Пользователь меняет статус вручную через меню проекта.

Статус отображается рядом с названием работы.

### 6. Фильтр несданных работ

Пользователь может переключаться между двумя режимами:
- все проекты;
- только несданные.

В режиме «Только несданные» скрываются работы со статусом
«Сдана». Остальные остаются видны.

Фильтр ничего не удаляет. Его состояние сохраняется
после перезапуска VS Code.

Поиск по проектам работает по всему списку,
независимо от фильтра боковой панели.

### 7. Прикрепление материалов

К проекту можно прикрепить:
- существующий файл на компьютере, например условие или отчёт;
- веб-ссылку, например на задание или репозиторий.

Пользователь задаёт название материала.
Материалы отображаются внутри проекта в боковой панели.

Плагин сохраняет только путь к файлу, а не копирует сам файл.
Веб-ссылки должны начинаться с http:// или https://.

Один и тот же материал нельзя прикрепить к проекту повторно.

### 8. Работа с материалами

Файлы открываются через системные приложения,
а веб-ссылки — через браузер.

Если файл переместили, можно указать его новый путь.

Материал можно открепить после подтверждения.
Сам файл на компьютере при этом не удаляется.

### 9. Сохранение данных

Список проектов, статусы и прикреплённые материалы
хранятся локально средствами VS Code и остаются
после закрытия редактора.

При отмене ввода данные не должны изменяться.

## Ограничения

- Плагин работает с локальными папками.
- Один проект соответствует одной корневой папке.
  Внутри неё может быть любое количество вложенных папок.
- Добавление из рабочего пространства с несколькими
  корневыми папками не поддерживается.
- Статусы пользователь выставляет сам.
